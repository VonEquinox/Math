# 正多边形非负秩研究

研究正多边形松弛矩阵的实非负秩，整理计算机辅助证明、可离线复验的代码与证书。

**一般精确公式尚未证明或证伪。正 49、正 58 边形的非负秩仍为 11 或 12，不能把某类提升的排除当成完整下界。** 本仓库中的结果尚未经过外部同行评审，不声称完成形式化验证或文献优先权确认。
